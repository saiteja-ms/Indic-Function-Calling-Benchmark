You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the PM-PRANAM
(PM Programme for Restoration, Awareness, Nourishment
and Amelioration of Mother Earth) service on the
UMANG app.

PM-PRANAM incentivises states and farmers to reduce
chemical fertilizer use (especially urea) and shift
to alternate nutrients — nano urea, organic fertilizers,
bio-stimulants, and soil amendments. It tracks subsidy
savings from reduced fertilizer use and channels a
portion back to states as grants. On UMANG, farmers
can check their nano urea adoption status, access
organic farming incentive applications, track
alternative nutrient subsidy benefits, check village-
level soil health improvement progress, and access
state-specific PM-PRANAM incentive programmes.

This usecase is DISTINCT from iFMS (fertilizer subsidy
DBT for chemical fertilizers) and SHC (soil testing).
PM-PRANAM focuses on the INCENTIVE and TRANSITION
layer — rewarding reduced chemical use and adoption
of alternatives.

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

THREE-AXIS EVALUATION DESIGN (CRITICAL)

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 5:
  Scheme information, nano urea product registry,
  organic input dealer lookup, and state incentive
  programme details are public. Enable single-turn,
  single-step, simple test cases.

PARALLEL-SAFE TOOL PAIRS — at least 4 pairs:
  Tools that read disjoint state and never mutate
  shared fields. Enable parallel-multiple cases.
  Natural pairs:
  - get_nano_urea_product_info + find_organic_input_dealer
  - get_state_incentive_programme + get_subsidy_saving_status
  - get_adoption_status + get_incentive_payment_status
  - get_village_soil_health_progress + get_state_incentive_programme

CHAIN-CAPABLE TOOLS — at least 5:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases. The required prior call is inferred
  from the parameter signature, NOT from text in
  the description.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover chemical fertilizer
  subsidy DBT (iFMS), soil sample collection (SHC),
  crop advisory (ATMA), PM-KISAN, PMFBY, MSP
  procurement, or weather forecasting — these belong
  to other UMANG services and enable irrelevance
  test cases.

These are real PM-PRANAM rules — encode them as
preconditions in tool descriptions without naming
which other tools must satisfy them.

- PM-PRANAM incentives are state-specific; not
  all states have active programmes; eligibility
  depends on the state's participation.
- Nano urea (liquid) is approved by the Fertilizer
  Control Order as a supplement but NOT a full
  replacement for urea; approved brands are listed
  by the Ministry of Chemicals and Fertilizers.
- Fertilizer use reduction is measured against the
  farmer's own purchase history in iFMS from the
  previous season; a minimum 10% reduction qualifies
  for incentive.
- Incentive amounts vary by state and the degree
  of reduction achieved; typically Rs 500-2000
  per acre per season.
- Incentive disbursement is via DBT to Aadhaar-linked
  bank account after verification.
- A farmer must have an issued Soil Health Card
  to apply for the PM-PRANAM incentive.
- Village-level data is aggregated and anonymised;
  individual farmer data is not visible to others.
- State subsidy savings are calculated centrally
  by the Ministry and disbursed as grants to states.
- A grievance about incentive denial requires the
  specific application_id.
- Training programmes are conducted through KVKs
  and are distinct from the incentive application.
