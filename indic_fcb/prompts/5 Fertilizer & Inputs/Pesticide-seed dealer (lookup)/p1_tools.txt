You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the Pesticide
and Seed Dealer Lookup service on the UMANG app.

This service enables farmers to find licensed pesticide
and seed dealers, verify dealer licenses, check product
registrations, report spurious or substandard inputs,
track complaint status, and access crop-wise input
recommendations. It is operated through the Central
Insecticides Board and Registration Committee (CIBRC)
for pesticides and the Ministry of Agriculture seed
portal for seeds.

This usecase covers ONLY the input quality, dealer
registry, and complaint layer — not fertilizer
(covered in iFMS, Cluster 5 Usecase 1) and not
crop advisory (covered in ATMA, Cluster 2).

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 6:
  Dealer lookup, product registration check, and
  banned product list are fully public. Enable
  single-turn, single-step, simple test cases.

PARALLEL-SAFE TOOL PAIRS — at least 4 pairs:
  Tools that read disjoint state and never mutate
  shared fields. Enable parallel-multiple cases.
  Natural pairs:
  - find_pesticide_dealer + find_seed_dealer
  - verify_pesticide_registration + check_banned_status
  - get_recommended_inputs + find_pesticide_dealer
  - get_seed_certification_status + verify_seed_variety

CHAIN-CAPABLE TOOLS — at least 4:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover fertilizer subsidy
  (iFMS), crop management advisory (ATMA), soil
  health cards (SHC), PM-KISAN, PMFBY, MSP
  procurement, or weather forecasting — these
  belong to other UMANG services and enable
  irrelevance test cases.

DOMAIN CONSTRAINTS (encode abstractly in descriptions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are real regulatory rules — encode them as
preconditions in tool descriptions without naming
which other tools must satisfy them.

- Pesticides must be registered under the
  Insecticides Act 1968 and listed in the CIBRC
  registry before sale is legal.
- Some pesticides are banned (Schedule I) or
  restricted (Schedule II); sale of banned
  pesticides is a criminal offense.
- Dealers must hold a valid license under the
  Insecticides Act; licenses are renewed annually
  by the state agriculture department.
- Seeds must be certified by the State Seed
  Certification Agency (SSCA) for truthful labelling.
- Seed lots have a certification tag number;
  farmers can verify the tag on the SSCA portal.
- Complaints about spurious pesticides require
  a product registration number or batch details
  for investigation.
- Complaints about unlicensed dealers require
  the dealer's name and location for inspection.
- Sample collection and testing is done by the
  state agriculture inspector; results take 30-45
  days.
- A complaint about a product already under
  investigation by another farmer is merged with
  the existing investigation.
- Crop-wise pesticide recommendations must specify
  the target pest and crop growth stage.
