You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the AgriStack
(Digital Public Infrastructure for Agriculture)
service on the UMANG app.

AgriStack is India's unified digital agriculture
infrastructure comprising three core registries:
the Farmers Registry (unique digital farmer ID
linked to Aadhaar and land records), the Crop Sown
Registry (real-time crop declaration by farmers
each season), and the Plots Registry (geo-referenced
land parcel data linked to revenue records). Together
these enable consent-based data sharing for credit,
insurance, advisory, and scheme delivery.

This usecase covers farmer digital ID management,
land record linkage, crop declaration, consent
management for data sharing, and registry data
access and correction.

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

THREE-AXIS EVALUATION DESIGN (CRITICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 4:
  Basic registry lookups and ID verification are
  public. Enable single-turn, single-step, simple
  test cases.

PARALLEL-SAFE TOOL PAIRS — at least 4 pairs:
  Tools that read disjoint registry data and never
  mutate shared state. Enable parallel-multiple cases.
  Natural pairs:
  - get_farmer_profile + get_plot_details
  - get_crop_declaration_status + get_plot_details
  - get_consent_log + get_farmer_profile
  - get_linked_schemes + get_crop_declaration_status

CHAIN-CAPABLE TOOLS — at least 6:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases. The required prior call is inferred
  from the parameter signature, NOT from text in
  the description.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover PM-KISAN payment
  processing, PMFBY insurance enrollment, MSP
  procurement token booking, eNAM mandi auctions,
  fertilizer DBT, soil test scheduling, or weather
  forecasting — these belong to other UMANG services
  and enable irrelevance test cases. AgriStack
  provides the IDENTITY and LAND RECORDS layer;
  it does not execute scheme transactions.

DOMAIN CONSTRAINTS (encode abstractly in descriptions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are real AgriStack rules — encode them as
preconditions in tool descriptions without naming
which other tools must satisfy them.

- A farmer digital ID (FID) is a unique 11-digit
  identifier linked to Aadhaar; one Aadhaar maps
  to one FID.
- Plot linkage requires matching Aadhaar-verified
  name against state revenue records (RoR).
- Crop declaration is seasonal: one declaration
  per plot per season (Kharif/Rabi/Summer).
- Declaration windows open after sowing completion
  and close before harvest; windows are state-specific.
- Consent is granular: a farmer can grant access
  to specific data fields (land records, crop data,
  financial history) to specific requestors for
  a defined period.
- Consent can be revoked at any time; revocation
  takes effect immediately.
- Data corrections require supporting documents
  (land ownership certificate, Aadhaar, etc.) and
  are reviewed by state revenue officials.
- A farmer's FID is portable across states if
  they migrate; migration requires re-linking
  land records in the new state.
- Linked scheme data is read-only; AgriStack
  does not enroll farmers in schemes directly.
- Registry data download generates a digitally
  signed certificate valid for 6 months.
