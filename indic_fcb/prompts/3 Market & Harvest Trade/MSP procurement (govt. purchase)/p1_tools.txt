You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the MSP Procurement
(Minimum Support Price government purchase) service
on the UMANG app.

MSP Procurement enables farmers to register for and
participate in government-run price support operations
where designated agencies (FCI, NAFED, state agencies)
purchase notified crops at the declared Minimum Support
Price directly from farmers. It covers registration,
token booking, produce delivery scheduling, weighment,
payment tracking, and grievance handling.

This usecase is DISTINCT from eNAM (open auction-based
private trade) and from Agri Marketing (FPO direct
trade). This covers ONLY government procurement at
MSP through designated procurement centres.

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

THREE-AXIS EVALUATION DESIGN (CRITICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 5:
  MSP rates, procurement centre details, and
  operation status are public information. Enable
  single-turn, single-step, simple test cases.

PARALLEL-SAFE TOOL PAIRS — at least 4 pairs:
  Tools that read disjoint state and never mutate
  shared fields. Enable parallel-multiple cases.
  Natural pairs:
  - get_msp_rates + get_procurement_centre_details
  - get_registration_status + get_token_status
  - get_payment_status + get_weighment_details
  - get_procurement_schedule + get_msp_rates

CHAIN-CAPABLE TOOLS — at least 6:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases. The required prior call is inferred
  from the parameter signature, NOT from text in
  the description.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover eNAM mandi auctions,
  Agri Marketing private trade, PM-KISAN income
  support, PMFBY crop insurance, fertilizer subsidy,
  soil health cards, or weather forecasting — these
  belong to other UMANG services and enable
  irrelevance test cases.

DOMAIN CONSTRAINTS (encode abstractly in descriptions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are real MSP procurement rules — encode them
as preconditions in tool descriptions without naming
which other tools must satisfy them.

- MSP rates are declared by the Cabinet Committee
  on Economic Affairs (CCEA) seasonally; Kharif
  MSP is declared in June-July, Rabi in October.
- Only notified crops are eligible for MSP
  procurement; the list varies by state.
- Farmers must register with their Aadhaar, land
  records, and bank account before procurement.
- Each farmer may sell up to the prescribed limit
  (varies by crop; typically 25 quintals per
  season for paddy, wheat has no cap for
  registered farmers).
- Tokens are issued for a specific centre and
  date; a farmer must physically deliver produce
  within the token window.
- Quality assay is mandatory; produce failing
  Fair Average Quality (FAQ) standards is
  rejected.
- Payment is made via DBT to the registered bank
  account within 72 hours of delivery and
  quality acceptance.
- A grievance about payment can only be raised
  after delivery is confirmed and quality is
  accepted.
- Procurement centres operate only during the
  declared procurement season window.
- A farmer who has sold through eNAM or private
  trade is still eligible for MSP procurement
  for remaining produce.
