You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the SDRF/NDRF
(State Disaster Relief Fund / National Disaster Relief
Fund) relief claim service on the UMANG app.

SDRF/NDRF provides compensation to farmers and rural
households for losses caused by natural calamities
— floods, droughts, cyclones, landslides, hailstorms,
earthquakes, and cold waves. Farmers submit claims
through the state revenue department portal integrated
with UMANG. Relief covers crop loss, house damage,
livestock loss, and human casualty compensation.

This usecase is DISTINCT from PMFBY crop insurance
(which is pre-paid premium-based insurance) and from
MSP procurement. SDRF/NDRF is post-disaster relief
funded by government, not by an insurance premium.

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

THREE-AXIS EVALUATION DESIGN (CRITICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 5:
  Disaster declaration lookup, relief rates, and
  calamity notifications are public. Enable
  single-turn, single-step, simple test cases.

PARALLEL-SAFE TOOL PAIRS — at least 4 pairs:
  Tools that read disjoint state and never mutate
  shared fields. Enable parallel-multiple cases.
  Natural pairs:
  - get_declared_calamities + get_relief_rates
  - get_claim_status + get_survey_status
  - get_payment_status + get_claim_status
  - check_eligibility + get_declared_calamities

CHAIN-CAPABLE TOOLS — at least 6:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases. The required prior call is inferred
  from the parameter signature, NOT from text in
  the description.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover PMFBY crop insurance
  (premium-based private insurance), PM-KISAN income
  support, MSP procurement, eNAM mandi trade, soil
  health cards, or weather forecasting — these belong
  to other UMANG services and enable irrelevance
  test cases.

DOMAIN CONSTRAINTS (encode abstractly in descriptions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are real SDRF/NDRF rules — encode them as
preconditions in tool descriptions without naming
which other tools must satisfy them.

- A claim can only be submitted after the state
  government formally declares a calamity for
  the affected district.
- SDRF norms define fixed per-unit relief rates:
  crop loss (per hectare, varying by irrigated
  vs rain-fed and crop type), livestock loss
  (per animal category), house damage (per
  damage category: fully damaged, severely
  damaged, partially damaged).
- Claims must be submitted within the declared
  claim window (typically 30-60 days after
  calamity declaration).
- A field survey is mandatory before relief
  is approved; survey is conducted by a
  revenue/agriculture official.
- A farmer may submit separate claims for crop
  loss, house damage, and livestock loss for
  the same calamity event.
- Payment is via DBT to the Aadhaar-linked
  bank account.
- A grievance about relief can only be raised
  after a claim has been submitted.
- NDRF norms apply when the calamity exceeds
  state capacity; SDRF applies for smaller
  events; the same claim workflow covers both.
- Duplicate claims for the same calamity event
  and loss category are rejected.
- A claim rejected due to survey findings can
  be disputed within 15 days of rejection.
