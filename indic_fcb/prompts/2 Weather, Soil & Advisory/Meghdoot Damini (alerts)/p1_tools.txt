You are building a function-calling benchmark dataset
in the style of the Berkeley Function Calling Leaderboard
(BFCL) and tau-bench.

Your task: Generate tool schemas for the Meghdoot
(agro-meteorological advisory) and Damini (real-time
lightning alert) services on the UMANG app.

Meghdoot delivers block-level 5-day agro-met advisories
to farmers via SMS, voice, and app. Damini provides
real-time lightning detection and strike alerts with
location-based warnings. Together they form the
weather-alert and field-safety layer of the Kisan
advisory ecosystem.

This usecase is DISTINCT from Kisan Suvidha weather
forecasts (which are district-level, general-purpose)
and from ATMA crop advisories (which are crop-management
focused). Meghdoot/Damini operates at block level with
agro-met integration and real-time lightning safety.

Generate AS MANY tools as needed for complete coverage.
Minimum 14, no upper limit. If a realistic farmer
workflow needs an additional tool not listed below,
add it.

THREE-AXIS EVALUATION DESIGN (CRITICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This benchmark evaluates LLMs on three independent
dimensions. The tool set MUST support test cases at
every meaningful cell of this 3-axis grid.

AXIS 1 — Conversation length:
  single-turn  : one user message
  multi-turn   : multiple user messages with state
                 evolving between them

AXIS 2 — Tool calls per turn:
  single-step  : exactly one tool call per turn
  multi-step   : multiple tool calls in the same turn
                 (parallel or parallel-multiple)

AXIS 3 — Task type:
  simple             : one clear tool, unambiguous
  parallel-multiple  : multiple tools called together,
                       no inter-call dependency
  irrelevance        : no tool can answer; model must
                       not call anything

To support all three axes, the tool set MUST include:

PUBLIC TOOLS (no session_token required) — at least 6:
  Meghdoot and Damini are safety and advisory services.
  The majority of lookups must be public so farmers
  can access warnings without authentication barriers.
  Enable single-turn, single-step, simple test cases.

PARALLEL-SAFE TOOL PAIRS — at least 5 pairs:
  Tools that read disjoint data and never mutate
  shared state. Enable parallel-multiple cases.
  Examples of natural pairs:
  - current lightning status + 5-day agro-met forecast
  - block-level rainfall advisory + crop-stage alert
  - active warning lookup + nearest safe shelter finder
  - subscription status + alert history

CHAIN-CAPABLE TOOLS — at least 4:
  Tools whose parameter signatures or preconditions
  imply a required prior call. Enable multi-turn
  chain cases. The required prior call is inferred
  from the parameter signature, NOT from text in
  the description.

DOMAIN-BOUNDARY CLARITY:
  The tool set must NOT cover general weather
  forecasting beyond agro-met context (IMD general
  public forecasts belong to Kisan Suvidha), crop
  management advisories (ATMA), soil testing (SHC),
  market prices (eNAM), PM-KISAN income support,
  PMFBY crop insurance, or PM-KUSUM solar pumps
  — these belong to other UMANG services and enable
  irrelevance test cases.

parameter and return schemas — never read it from prose.

DOMAIN CONSTRAINTS (encode abstractly in descriptions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are real Meghdoot/Damini rules — encode them as
preconditions in tool descriptions without naming
which other tools must satisfy them.

- Meghdoot advisories are at block level (sub-district)
  and updated every 12 hours using IMD AWS data.
- Advisories are crop-stage aware and change content
  based on the farmer's registered sowing date and
  crop type.
- Damini detects lightning using IITM Pune sensor
  network; coverage is India-wide but density varies
  by region.
- Lightning alerts are issued when strike density
  exceeds a threshold within a 20 km radius of the
  farmer's registered location.
- Safety levels: safe (no strikes within 20 km in
  60 min), caution (1-5 strikes), danger (6+ strikes).
- Alert subscriptions are tied to a registered
  location (block + village); a farmer may have
  up to 3 registered locations.
- Advisory SMS is delivered in the farmer's preferred
  regional language.
- Historical rainfall is available for up to 10 years
  at block level from the India-WRIS network.
- Seasonal monsoon outlook is published by IMD in
  April (southwest monsoon) and September (northeast
  monsoon); it is probabilistic, not deterministic.
- A grievance about a missed alert requires the
  subscription_id and the expected alert date.
